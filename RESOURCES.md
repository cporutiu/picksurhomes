# Picksur Homes — Resource Map

## Hosting
- **Provider:** Netlify
- **Purpose:** Deploys and serves the Next.js site

## Domain Registrar
- **Provider:** Bluehost
- **Purpose:** Domain registration and ownership

## DNS Management
- **Provider:** Cloudflare
- **Purpose:** DNS records management

## Email Routing
- **Provider:** Cloudflare
- **Purpose:** Routes incoming email for the domain

## Web Forms
- **Provider:** Web3Forms
- **Endpoint:** `https://api.web3forms.com/submit`
- **Key:** Stored in `.env.local` as `NEXT_PUBLIC_WEB3FORMS_KEY`
- **Purpose:** Handles contact form submissions on the site
